# 시안 → 레시피 → 감량 (prop-recipe-kit)

Unity 패키지 `com.proprecipe.kit`(네임스페이스 `PropRecipe`)의 `PropParts`로 부품을 쌓고, `PropBaker`로 굽고, `PropMeasure`·`PropCapture`로 확인한다. 블렌더는 FBX가 필요할 때만(스킬 `prop-blender-headless`).

## 반드시 지킬 것

1. **크기 기준부터 정한다.** 시안에서 캐릭터·문·침대처럼 크기를 아는 물건을 하나 골라 m로 환산하고, 가구의 외곽 치수(가로·깊이·높이)를 먼저 숫자로 적는다. 피벗 = 점유 영역 바닥 가운데, 정면 = +Z.
2. **덩어리 먼저, 장식은 나중.** 두툼한 덩어리 3~6개로 실루엣을 맞춘 뒤 장식 3~8개를 얹는다. 색은 2톤 + 문양 1개가 기본.
3. **눈으로 확인하기 전에 다음 가구로 넘어가지 않는다.** 맞음새 시트(같은 카메라 각도, 정면·좌 3/4·우 3/4·옆)를 시안 옆에 붙여 「실루엣·대표 부품·장식·색」 4항목을 본다.
4. **재질은 프로젝트 어댑터(`IPropMaterialProvider`) 규칙으로만 만든다.** 새 셰이더를 만들지 않는다.
5. **감량은 원본(기본 `PropLod`)을 남긴 채 따로 굽는다.** 감량 판과 원본을 같은 카메라로 비교해 IoU·삼각형을 적는다.
6. **수치 없이 「가볍다」고 하지 않는다.** `PropMeasure` 결과(삼각형·정점·재질 수·해시)를 남긴다.

## 순서

1. **크기 표**: 시안의 기준 물건 → m 환산 → 가구 외곽 치수. 방 안 가구라면 바닥의 55~65%를 덮는지, 캐릭터 키가 침대 길이의 60% 이상으로 보이는지 같이 본다(시안 비율).
2. **도형 고르기**(덩어리)

   | 모양 | DSL |
   |---|---|
   | 둥근 상자(몸통·판·다리) | `Box(mat, center, size, r)` — 반지름 0.025 이하는 모서리 분할 2 |
   | 원기둥·그루터기·통(굴곡 가능) | `Cyl(mat, pos, radius, height, bevel, rTop, euler, lobes, amp, segments)` |
   | 공·쿠션 | `Ball(mat, center, size)`, 반구 `Dome` |
   | 임의 단면 회전체(화분·램프갓) | `Lathe(mat, key, profile, pos, ...)` — 단면은 (반지름, 높이) 아래→위 |
   | 판 모양(등받이·간판·문양) | `Plate`와 `Arch`·`Heart`·`Star`·`FlowerPlate`·`Cloud`·`RoundRect`·`Shield`·`Crescent`·`Scallop`·`Wave`·`Polygon` |
   | 고리·테두리 | `Ring(mat, center, major, minor, euler, arcDeg)` |
   | 문·뚜껑·서랍 | `BeginGroup(name, pivot)` … `EndGroup()`(따로 굽는 자식) |

3. **장식**: 문양 판을 덩어리 앞면에서 0.02~0.04 m 띄워 붙인다. 같은 색은 같은 재질 키로 묶는다(재질 수 = 서브메시 수 = 드로우 콜).
4. **맞음새 시트**: `PropCapture`로 네 방향 + 게임 카메라 각도를 찍어 시안 옆에 붙인다. 틀린 곳을 고치고 다시 찍는다.
5. **감량**: `PropLod.Reduced()`(분할 0.375배·최소 6, 상자 모서리 1분할, 외곽선 1% 단순화, 판 테두리 1분할)로 굽고 `PropBaker`의 묻힌 면 제거를 켠다. 원본과 같은 카메라로 비교한다.
   - 파일럿(2026-11-25, 가구 3개): 삼각형 72~92% 감소, 실루엣 IoU 0.986~0.991, 두 번 구워 해시 동일.
   - 예산을 정확히 맞춰야 하면(큰 가구 등) 블렌더 경로의 `target_tris`를 쓴다. 생성기 감량에는 목표 삼각형에 맞추는 수단이 없다.
6. **재질 1개로 합치기(선택)**: `PropBakeMode.Palette`(팔레트 UV + N×1 텍스처). 툰 셰이더가 재질마다 그림자 색을 따로 받으면 색이 달라진다(파일럿 ΔE 14~20). 어댑터에서 색을 재고 정한다.
7. **기록**: 삼각형·정점·재질·IoU·해시와 시트를 작업 폴더에 남긴다.

## 감량 값 고르기

| 상황 | 권장 |
|---|---|
| 상자 위주 가구 | `boxSegMax` 1~2. 모서리 둥글기가 보이는 큰 가구는 2 |
| 회전체·공 | `segScale` 0.375~0.5, `segMin` 6. 굴곡(`lobes`) 있으면 키트가 굴곡 × 4 이상으로 올림 |
| 판(외곽선) | `simplify` 0.01(모서리 점 유지). 「N개마다 솎기」는 모서리가 빠져 쓰지 않음 |
| 겹쳐 쌓은 부품 | 묻힌 면 제거를 켠다(트리처럼 겹침이 많으면 절반 가까이 사라짐) |

## 함정

- 부품마다 다른 재질 키를 남발하면 드로우 콜이 늘어난다. 색이 같으면 키를 합친다.
- 문양 판을 덩어리 속에 묻으면 묻힌 면 제거가 지워 버린다. 앞면에서 띄운다.
- 판의 `euler` 기본이면 앞면이 +Z다. 바닥에 눕히려면 (90,0,0).
- 같은 레시피라도 `PropLod`가 다르면 다른 메시다. 비교할 때는 프리셋 이름과 해시를 같이 적는다.
